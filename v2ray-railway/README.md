# X4G V2Ray / Xray Railway build

این پوشه برای نسخه‌ی پایدار کلاینت V2Ray/Xray روی Railway است و به کد فعلی X4G دست نمی‌زند.

## معماری

- خروجی کلاینت: VLESS
- ترابردهای موجود در X4G: WebSocket و XHTTP
- Railway به‌عنوان لایه‌ی HTTP/HTTPS استفاده می‌شود.
- برای خروجی واقعی یک کشور خاص، خود سرویس Railway باید در همان کشور اجرا شود یا یک exit node/proxy در آن کشور به آن متصل شود.

## کشورهای هدف

ساختار پروژه برای Nodeهای مستقل طراحی شده است:

- Netherlands
- Germany
- United Kingdom
- United States

هر کشور باید exit واقعی همان کشور داشته باشد؛ انتخاب نام کشور به‌تنهایی IP خروجی آن کشور را ایجاد نمی‌کند.

## پایداری

- Restart policy روی Railway فعال است.
- وضعیت X4G در DATA_DIR ذخیره می‌شود؛ برای Railway یک Volume روی `/data` لازم است.
- اسرار و توکن‌ها نباید داخل Git commit شوند و باید به‌صورت Environment Variable تنظیم شوند.

## امنیت و محدودیت

هیچ روش ارتباطی را نمی‌توان تضمین کرد که «غیرقابل شناسایی» یا «غیرقابل مسدودسازی» باشد. هدف این نسخه، استفاده از ترابردهای استاندارد و مقاوم در برابر خطا و حفظ پایداری عملی است.
